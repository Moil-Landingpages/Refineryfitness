Built and verified

The developer half of search work. All of this is in the code, covered by an automated test, and re-checked on every deploy.

Crawling &amp; indexing

  • ✓
    robots.txt published and permissive

    Generated from code, not hand-edited. Googlebot and Bingbot are named and allowed, and the sitemap is declared in it.

    Moil
  • ✓
    AI answer engines explicitly allowed

    OAI-SearchBot and ChatGPT-User (ChatGPT), Claude-SearchBot and Claude-User (Claude), PerplexityBot and Perplexity-User. These are the crawlers that fetch a page to cite it in an answer — separate from the ones that scrape for model training.

    Moil
  • ✓
    XML sitemap generated from one page registry

    All 11 indexable pages. The sitemap is built from the same list that builds the site navigation, so a new page cannot ship unlisted — and an unlisted page is the most common way a new page never gets found. /gear is deliberately excluded — see below.

    Moil
  • ✓
    Self-referencing canonical on every page

    Each page declares itself as the canonical URL, so two paths that render the same content cannot compete with each other in search.

    Moil
  • ✓
    No page left unlinked

    Every page is reachable from the site navigation or footer. A page with no internal links pointing at it is effectively invisible, however well written.

    Moil

Pages built for search intent

  • ✓
    Location pages for Buda, Kyle and Hays County

    Each with its own original copy about how training actually works in that place. We deliberately did not mass-produce city pages by swapping a name — Google classes that as doorway pages and it carries a manual-action risk.

    Moil
  • ✓
    A page for each program

    Strong Start, 1:1 Training, Mobile Training and Virtual Coaching, each answering what it is, who it suits and what it costs in time.

    Moil
  • ✓
    Personal-training hub, About and Contact

    The hub collects the programs; About carries Jeff's credentials as a person entity; Contact gives one clear path to book.

    Moil
  • ✓
    Unique title and description on every page

    Checked automatically — a duplicate fails the build. The Buda page title was rewritten once already because it exactly matched the homepage, which would have had the two competing for the site's most valuable search.

    Moil
  • ✓
    Social preview image on every page

    So a link shared to a text message, WhatsApp or Facebook renders as a proper card rather than a bare URL.

    Moil

Structured data (how machines read the business)

  • ✓
    Business marked up as a HealthClub and LocalBusiness

    Name, logo, locality, service area, contact and the full program list, cross-referenced as one connected entity rather than scattered fragments.

    Moil
  • ✓
    Jeff marked up as a Person, linked to the business

    Includes his social profiles, so Google can resolve one identity across the web instead of guessing.

    Moil
  • ✓
    LinkedIn added to the profile list

    This closed the last open item from the 7 August review call. It now feeds the structured data, the About page and the footer from one place.

    Moil
  • ✓
    Programs marked up as Services with their areas served

    Each program names the places it is actually offered in, read from a single service-area file so copy and markup can never drift apart.

    Moil
  • ✓
    FAQ marked up for answer engines

    Questions and answers in a format ChatGPT, Claude and Google can quote directly.

    Moil
  • ✓
    No star rating published — on purpose

    Google does not allow a business to publish its own collected reviews as a rating on its own site, and doing it anyway risks a penalty for zero gain. The automated test fails the build if one is ever added. Real stars come from the Google Business Profile.

    Moil

Readable by AI assistants

  • ✓
    Content present in the HTML, not built by JavaScript

    Most AI retrieval crawlers do not run JavaScript. Navigation, FAQ answers and page copy are in the served HTML, so an assistant reads the same page a person does.

    Moil
  • ✓
    Facts written as labelled values

    Prices, durations, service areas and formats are marked up as labelled pairs rather than buried in prose, so a fragment lifted out of the page still carries its meaning.

    Moil
  • ✓
    One H1 and one main landmark per page

    Checked automatically. Duplicated or missing landmarks are a common reason a parser misreads what a page is about.

    Moil
  • ✓
    Breadcrumb trail, visible and marked up

    The visible trail and its structured data are generated from one source, so they cannot disagree — which is the condition Google states for showing breadcrumbs in results.

    Moil

Affiliate gear page

  • ✓
    Every affiliate link tagged sponsored and nofollow

    Google requires paid links to be disclosed in the markup. The automated test checks all five links on every build.

    Moil
  • ✓
    Affiliate disclosure above the links, not buried

    The FTC asks for disclosure that is clear and conspicuous, and before the reader clicks.

    Moil
  • ✓
    Page kept out of search results and the sitemap

    A short list of outbound links is thin content by definition, and this site's whole position rests on not publishing thin pages. It still works perfectly from a bio link or the footer.

    Moil

Automated safety net

  • ✓
    A test suite that fails the build on an SEO regression

    npm run check:seo checks all 11 pages for a unique title and description, a correct canonical, exactly one H1 and one main landmark, a social image, valid structured data with no broken internal references, a breadcrumb trail, and the absence of a self-published rating — plus the affiliate rules and the AI-crawler permissions. It runs as a release gate.

    Moil

Google Business Profile and local listings

  • !
    Create the service-area profile, if eligible

    Approved name, category, hidden address, the confirmed service area, hours and the program list. This is what puts the business into map results and it is where real star ratings come from.

    Client

    Google, Bing Places, Apple Business Connect, Facebook, Instagram and any directory listing must agree exactly. Disagreement between listings is a leading cause of weak local ranking.

    Client
  • !

    Ask after a good session. Never incentivise, never bulk-request — both are against Google's policy and both are detectable.
